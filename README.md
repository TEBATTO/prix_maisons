# Prédiction du Prix des Maisons

## Contenu du Notebook
Le notebook contient les sections suivantes :

1. **Exploration et Préparation des Données**
   - Exploration des données (analyse statistique et visualisation, imputations des valeurs manquantes).
   - Préparation des données pour le machine learning, y compris la transformation des caractéristiques et la normalisation.

2. **Optimisation des Modèles**
   - Utilisation de la validation croisée pour évaluer la robustesse des modèles.
   - Optimisation des hyperparamètres de `RandomForestRegressor` à l'aide de `GridSearchCV` pour améliorer les performances.


## Modèles Utilisés
- **RandomForestRegressor** : Utilisé avec une recherche des meilleurs hyperparamètres.
- **LinearRegression** : Utilisé comme modèle de base.

## Conclusion
Le projet a suivi une méthodologie rigoureuse, incluant la validation croisée et l'optimisation des hyperparamètres, tout en respectant les bonnes pratiques de code (PEP8) et la structuration du projet avec GitLab. Cette approche nous a permis de comprendre les différentes étapes de la data science et de développer un modèle de prédiction performant dans un contexte d'entreprise.

1. Clonez ce repository.
2. Ouvrez le notebook `notebook.ipynb` dans Jupyter Notebook.
